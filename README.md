# THE LAST ROOM

เกมสยองขวัญแนวไขปริศนาบน Roblox ตามหาเลขที่ซ่อนอยู่ 4 ตัว
เพื่อปลดล็อกตู้เซฟ นำกุญแจไปเปิดห้อง 13 และเปิดเผยความจริง

# วิธีเปิดไฟล์
1. ติดตั้ง Roblox Studio
2. ดาวน์โหลดไฟล์ room-13-lost-night.rbxl จาก repo นี้
3. เปิดไฟล์ด้วย Roblox Studio
แนะนำให้เล่นใน roblox player ปกติครับ เพราะใน roblox studio จะไม่ได้เริ่มจากlobby
ลิ้งเกมส์ https://www.roblox.com/share?code=e83421f829a6c044acfddc440785828a&type=ExperienceDetails&stamp=1791429226344

# วิธีเล่น
1. สำรวจและหาเลขที่ซ่อนอยู่ 4 ตัว
2. ใช้เลขปลดล็อกตู้เซฟ
3. นำกุญแจไปเปิดห้อง 13
